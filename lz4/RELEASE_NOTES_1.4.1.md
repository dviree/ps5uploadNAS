# LZ4 Compression 1.4.1

- Buy Me a Coffee on the About page: a QR code in the PS5 app you can scan
  with your phone, and a button on the web page.
- The About page in the PS5 app cut the credits off mid-sentence. They show
  in full again.

Everything from 1.4.0 is included: bundled LZ4 profiles picked automatically,
a games-only library, LZ4 and read speed on `.exfat` images while the app is
open, and the `.ffpfsc` uncompress fix. See
[RELEASE_NOTES_1.4.0.md](RELEASE_NOTES_1.4.0.md).

## Install

1. Add `lz4-compression.elf` to Payload Manager, so it sits at
   `/data/pldmgr/payloads/lz4-compression/lz4-compression.elf`.
2. Unzip `LZ4-Compression-PPSA99420.zip` and copy the `PPSA99420` folder to
   `/data/homebrew/PPSA99420` over FTP (replace the old one). ShadowMount+
   adds the `LZ4 Compression` tile (close any running game if it doesn't show
   up).
3. Open the tile.
