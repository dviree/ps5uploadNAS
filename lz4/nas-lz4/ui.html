What the buttons do

Check all read-only

Looks at every game and changes nothing. It runs two checks and shows the result under Recent actions on the Activity tab:

  • Every LZ4 game in the LZ4 folder: the pack format (AMPRPAK4 index, AMPRDAT3 volumes, CRC and ampr_emu.index sidecars); that fakelib/libSceAmpr.sprx is exactly APR-EMU PackedStdio 0.4.2.1 (SHA-256), the only build that reads LZ4 packs; that the files the PS5 opens straight from disk (PlayGo markers, empty placeholders, some boot files) are next to the packs and not only inside them; that the runtime folder named in eboot.bin has the right upper/lower case; and that games using PlayGo have a PlayGo emulator in fakelib.
  • Every original in the library: is it already LZ4, can it become LZ4 (a program imports libSceAmpr), or not, and why. exFAT images are read without unpacking them.

Results are saved with each game's file sizes and dates. A game whose files haven't changed is not read again; new or changed games are. If something is wrong, a Repair button appears with the result.

Full re-check read-only

The same checks as Check all, but every LZ4 game and every original is read again, ignoring the saved results, and the saved results are replaced. Use it after changing files by hand, copying games in some other way, or when a result looks wrong. It takes longer: every eboot and every image is read.

Neither check decodes the packs again; that happened byte for byte when each game was packed (see Compress).

Repair changes LZ4 games

Appears after a check that found problems. For each LZ4 game that needs it: puts the right APR-EMU back, writes out the files the PS5 reads from disk from inside the packs, renames the runtime folder to the case the game asks for, and copies a PlayGo emulator in if the game needs one. Nothing is repacked and originals are never touched.

Compress all writes new LZ4 copies

Queues every game that can be LZ4, except .ffpfsc images (already compressed, so an LZ4 copy is usually as large or larger; use Compress on one if you want it anyway), and packs them one at a time (one at a time because each needs the CPU and space). For every game, in six steps:

  1. Source: a game folder is used as it is; an .exfat, .ffpfs or .ffpfsc image is unpacked to a work folder on the NAS and every file is checked against the image (and its .vhash if there is one).
  2. Check: a program must import libSceAmpr, otherwise APR-EMU would never load and the game is skipped.
  3. Pack: LZ4 HC level 9 with the game's profile, using all cores but one at low priority.
  4. Verify: every chunk is decoded and compared with the original.
  5. Restore test: the whole game is unpacked again and every file compared byte for byte.
  6. Publish: the boot files are fixed and the result moves to the LZ4 folder.

Originals are read-only and never changed; an existing LZ4 game is never overwritten. If a job is already running, this waits for it. A failed game keeps its work folder for troubleshooting.

Continue queue

Only shown when packing was interrupted (the container restarted, the NAS rebooted, or Stop was pressed). Continues the same game from its last finished step (a step that was cut off is done again), then the rest of the queue. The queue also continues by itself when the container starts.

Compress one game

The same as Compress all for a single game; tap a game to see it.

Duplicates on the NAS

The same game (Title ID) is in the library more than once, as other versions or as a folder and an image. The newest is marked; deleting an older one frees its space (needs DELETE_ORIGINALS=yes). Its LZ4 copy, if any, stays.

RAR archives in the library

A game packed as RAR parts (name.part1.rar, …) is extracted with unrar (every file's CRC checked) and made into a checked .exfat in _extracted in the library, which then shows up as a game. The RAR files stay until you delete them (after a finished extract, with DELETE_ORIGINALS=yes).

ELF on the PS5 · pkg-receiver

The PS5 side is pkg-receiver from pkg-sender (MIT) in this project's Glass build, a payload on port 12800. It installs .pkg games, updates and DLC with the PS5's own installer, downloading them straight from this NAS, and its own page on the PS5 (the pkg remote installer shortcut on the home screen) lists this NAS's packages to install with the controller. Install and start copies it into Payload Manager and starts it (once, or for a new version); Start starts the copy already on the PS5, and this page also starts it by itself when the PS5 is on and it isn't running (after a restart).

Notifications

A push notification when packing, a check, a transfer to the PS5 or a download by the PS5 finishes or fails. Use an ntfy topic (https://ntfy.sh/your-secret-topic, then subscribe to it in the ntfy app) or any webhook, e.g. Home Assistant's (JSON with title, message, ok). Empty: off.

PS5 storage

The internal SSD's size and free space come live from pkg-receiver. For other drives, Set size once (as PS5 Settings › Storage or the drive's label shows it) and Measure adds up the files on the drive.

1. Address

Send to PS5 copies a game straight over FTP to the PS5's ftpsrv (port 2121), not through a mount. Every file's size is checked and program files are compared byte for byte; an interrupted transfer continues where it stopped. The address and folder are saved as soon as you change them.

2. Pair for wake-up (Remote Play, like Chiaki)

Pairing lets this page wake the PS5 from rest mode, by itself before a transfer or with Wake PS5 now. You only do it once.
  1. PSN account ID of the account signed in on the PS5, in the base64 form Chiaki uses: 12 characters ending in =, for example Ab3dEf7hIjk=.
    • Already set up in Chiaki / chiaki-ng? Use the same ID you entered there.
    • Normal PSN account: chiaki-ng can look it up when you sign in with PSN (in its settings).
    • Fake sign-in on a jailbroken PS5 (offline-activated account): the ID the activation tool gave the account. A decimal number or 0x hex works too; it is converted.
  2. On the PS5 open Settings › System › Remote Play › Pair Device. It shows an 8-digit PIN for a few minutes.
  3. Enter both here and press Pair while the PIN is still on screen.

Or: key from Chiaki

Already paired in Chiaki? Instead of pairing again, enter its rp_regist_key (8 hex characters, in Chiaki's settings file) and press Save.

PS5 files (FTP)

Browse the PS5 over ftpsrv: the internal drive (/data), USB drives (/mnt/usb0) and extended storage (/mnt/ext0). Tap a file to download it as it is on disk, or ZIP to download a whole folder. Upload files and folders from this device into the folder you are in (inside /data, /mnt/usbN or /mnt/extN). Delete works only inside /data, /mnt/usbN and /mnt/extN, at least two folders down, and asks first.

Games on the PS5

Game folders in homebrew and etaHEN/games on every drive, and installed PS4 games (/user/app), read over FTP.

Save data backups

Copies every save folder on the PS5 (PS5 savedata_prospero and PS4 savedata, every user) to the NAS over FTP, only reading on the PS5. Each backup is kept by date in state/saves; download one as a .zip, or Restore one game's saves to the same user on the same PS5 (close the game first). Saves are tied to the PS5 user, so restoring to another console or user may not work.
